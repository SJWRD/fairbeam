## Reproductions and measured limits

Independent controlled inputs on the old tree and corrected code gave:

- A 30+60-degree x rotation of a y-normal extrusion selected y before, z after; exact 90 degrees selects z.
- A native epsilon-16 zero-strength Lorentz slab was classified as zero dielectrics before, one after.
- With `A = [[1, .1], [.1, 1]]` and known matched fields `[2, 4]`, recovered first field was 2.4 before, 2 after.
- For `S = .7 * ones((2, 2))`, column power is .98, but maximum coherent output power is 1.96.
  The old passivity flag was true; the corrected flag is false.
- A NaN S11 goal had cost zero and was met before; it now has penalty 10000 and is not met.
- The source-editor race regression fails on the old source (`A` replaces `B`) and passes on the corrected store.

Run the focused numerical/native-geometry tests with the openEMS Python environment:

```sh
cd python
python -m unittest discover -s tests -p test_oct17_review.py -v
```

An optional sequential native equivalence control is reproducible from the repository root:

```sh
python scripts/validate-review-native.py --out <new-output-directory>
```

The control uses a 20 x 20 x 1 mm epsilon-16 slab, a 50-ohm z port, 1–3 GHz, MUR boundaries,
20 cells/wavelength, 10 mm padding, one CPU thread and a -50 dB energy criterion. The second run
uses `Simulation.dispersive` with a zero-strength Lorentz pole. On Windows both meshes had
14,196 interval cells, both runs stopped at 2,380 steps with energy convergence reported, and
the maximum complex S11 difference across 31 samples was **0**. This establishes equivalence
of these two material paths, not antenna accuracy or mesh convergence.

Spatially weighted dispersive properties, nonpositive-band singularities and direct native Debye
properties that cannot be bounded safely require an explicit validated mesh. The supported
`Simulation.dispersive` Debye/DS route still uses its Lorentz fit. The bound can be conservative
near a narrow pole and may produce a larger mesh.

## Existing results

Rebuild and rerun affected composed-extrusion or dispersive-auto-mesh models. Re-evaluate old
optimizer winners for energy and mesh convergence. Regenerate embedded element patterns when
matched-basis array results are needed; old scalar-normalized fields cannot be repaired from
rounded summaries alone. Raw per-run far fields and their power accounting are not rewritten.
Field-plane unit and realized-gain presentation fixes apply when opening existing bundles.

Local Windows validation passed: 1,985 Python tests (9 skipped), 232 EN/TR browser steps
(`--skip-run`), typecheck, production build, Designer/export checks, legal and license checks.
The first browser attempt overlapped source edits; it was replaced by the complete successful
run against frozen source. A native-optimizer mock was updated to declare the convergence it
represents; production convergence checks were not weakened to satisfy that fixture.

Validation is scoped to regressions, the local native Python suite, export/Designer checks and
EN/TR browser workflows. It does not establish a universal accuracy bound for all antennas,
and it is not a macOS installer qualification or a new release.
