# Fairbeam 0.8.4 — stabilization notes draft

This is an unpublished working draft, not an announcement. The application version remains
0.8.3. Before preparing a release, the maintainer must approve and merge
[PR #301](https://github.com/ismailakdag/fairbeam/pull/301) after its exact commit passes native
Mac review. Any later fixes need their own review and validation. The final notes must describe
only changes included in the release tag.

## Changes already on main

- Preserve saved-design and result ownership across first Save, Save As, model switches and
  failed preview validation. Improve recovery guidance for missing workspaces and damaged
  runtimes, while keeping recovery operations explicit.
- Keep viewport dimensions, report tables and drawing figures consistent for mm, cm and m
  models. Preserve completed convergence outcomes when Stop races with completion, and keep
  integer sweep values consistent with preview.
- Improve English and Turkish feedback for native file operations, queue actions, exports,
  numerical inputs and reference-data drops. Recognize macro text on Home and Design without
  changing hidden reference data; Results continues to parse measurement data first.
- Retain the focused Compare checkbox when the result index refreshes. Space continues to
  toggle that row, and Escape returns focus to the Compare control.
- Show endpoint contact feedback for discrete ports and lumped R/L/C elements. Selecting one
  highlights the touching primitives; rings distinguish connected, disconnected and unknown
  endpoints. This is a geometry-placement aid, not proof of final mesh connectivity or a
  validated simulation connection.
- Repair standalone checks and document their prerequisites. Add citation metadata and
  document the source-archive process.

Sources: [#258](https://github.com/ismailakdag/fairbeam/pull/258),

## Candidate changes awaiting PR #301

These items are pending and must not be presented as shipped:

- Strengthen exit confirmation around active and queued work, unsaved drafts and pending Save
  operations. Preserve ownership when a question is canceled or newer work starts.
- Correct native menu and shortcut behavior, macOS menu labels and application metadata.
- Improve initial focus in Simulation settings and retain Results with the minimized ribbon.
- Correct plot-export numbers, explanatory text and line styles, and keep CSV decimal and
  Unicode output consistent. Preserving exported user names remains conditional on fixing
  combining-mark handling for NFD names.
- Align English and Turkish interface wording and source documentation with the current app.
  If the desktop server is unavailable, explain how to restart Fairbeam; this does not add
  automatic server recovery.
