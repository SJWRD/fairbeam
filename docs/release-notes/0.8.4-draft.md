# Fairbeam 0.8.4 — stabilization notes draft

This is an unpublished working draft, not an announcement. The application version remains
0.8.3. The changes below have landed on main, but final release preparation and validation are
still pending. Any later fix needs its own review. Final notes must describe only changes
included in the release tag.

## Changes already on main

- Preserve saved-design and result ownership across first Save, Save As, model switches and
  failed preview validation. Improve recovery guidance for missing workspaces and damaged
  runtimes, while keeping recovery operations explicit.
- Keep viewport dimensions, report tables and drawing figures consistent for mm, cm and m
  models. Preserve completed convergence outcomes when Stop races with completion, and keep
  integer sweep values consistent with preview.
- Improve English and Turkish feedback for native file operations, queue actions, exports,
  numerical inputs and reference-data drops. Recognize macro text on Home and Design without
  changing hidden reference data; Results continues to parse measurement data first.
- Retain the focused Compare checkbox when the result index refreshes. Space continues to
  toggle that row, and Escape returns focus to the Compare control.
- Show endpoint contact feedback for discrete ports and lumped R/L/C elements. Selecting one
  highlights the touching primitives; rings distinguish connected, disconnected and unknown
  endpoints. This is a geometry-placement aid, not proof of final mesh connectivity or a
  validated simulation connection.
- Strengthen exit confirmation around active and queued work, unsaved drafts and pending Save.
  A failed close-handler reply cancels the current decision; the next explicit Quit/Close
  probes again. A recent repeated script error can use the exit fallback, while valid replies
  clear that opportunity. Update consent remains available and never uses the error fallback.
- Guard native New/Open/Start/Design/Examples/Open Recent while a modal owns the interaction.
  Correct native menu conventions and application metadata, improve initial Simulation settings
  focus, and retain Results with the minimized ribbon.
- Correct figure-export numbers, notes and dash patterns; preserve combining marks in raw
  names. The combining-mark/NFD fix is merged and verified in the browser only; native NFD
  exports were not run. Keep toolbar CSV's UTF-8 BOM distinct from package/clipboard data
  while preserving decimal values.
- Align English and Turkish guidance with current project, solver and ribbon workflows.
  When the desktop server is unavailable, explain how to restart Fairbeam; this does not add
  automatic server recovery.
- Avoid repeatedly transferring historical result arrays during ordinary/research list
  polling, while keeping full selected-result detail available and preserving cancellation.
- Record completed-result provenance even while a long Save holds the workspace lock.
  Publish complete records exclusively and preserve conflict and linked-directory checks.
- Bind server startup attempts to their generation, child and ready state. Superseded workers
  cannot replace or stop the current server; updater interruption remains recoverable and
  accepted application exit performs terminal cleanup.
- Preserve failed and recovered browser-attempt evidence, plus prelaunch and same-launch
  diagnostics. These changes improve investigation; they do not establish a fix for #251.
- Repair standalone checks and document their prerequisites. Add citation metadata and the
  source-archive process, including the corrected published author and affiliation forms.
