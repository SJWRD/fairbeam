# Appearance customization

**General settings › Appearance** controls the interface, charts and 3D view. Geometry, materials and simulation data stay unchanged.

## Coordinated themes

- **Forest · dark green**: dark theme, Forest interface palette, Teal accent, Distinct colors charts and Slate 3D background.
- **Academic · light blue**: light theme, Ocean interface palette, Blue accent, Distinct colors charts and Warm paper 3D background.

Applying either turns custom colors off and restores the default Plex fonts and **Normal · 2 px** line weight. Simulation preferences are preserved. You can then change each setting individually.

## Fonts and palettes

| Setting | Options |
| --- | --- |
| Interface font | IBM Plex Sans (default), System sans serif, Arial / Helvetica |
| Numbers and code font | IBM Plex Mono (default), System monospace, Consolas |
| Interface palette | Current (default), Ocean, Forest, Plum, Stronger contrast |
| Accent color | Copper (default), Blue, Teal, Violet |
| Chart colors | Current (default), Distinct colors, Muted colors |
| Chart line weight | Fine · 1.5 px, Normal · 2 px, Bold · 3 px |
| 3D background and grid | Current (default), Slate, Warm paper, Blueprint |

Each palette row has its own **Reset** button. Unavailable fonts use local fallbacks; numbers and code retain a separate monospace font. **Distinct colors** and **Muted colors** offer stronger trace contrast in light mode. The default palette is retained, including the lower contrast of some traces.

## Custom colors

Expand **Custom colors** to override the accent, primary chart trace, 3D background or grid color. Turn an override off to return to its selected preset. Accent buttons choose black or white text for readability; choose custom chart and grid colors that remain visible against the background.

## Persistence and reset

Choices are stored locally across restarts and light/dark theme changes. Invalid stored options independently recover to their defaults without discarding other valid settings. **Reset appearance** restores theme, fonts, Current/Copper palettes and Normal · 2 px lines, and turns custom colors off.
